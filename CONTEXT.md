- Neurólogo: "Tienes razón, no había checado bien tu peso"

### **Medicación actual (auto-ajustada por Emmanuel):**

**Levetiracetam 1000mg/día**
- Dosis: 1000mg en una sola toma (~4pm)
- Objetivo: Cobertura nocturna (4pm-4am)

**⚠️ PROBLEMA FARMACOLÓGICO:**
- Levetiracetam tiene vida media de 6-8 horas
- Tomando 1000mg a las 4pm:
    - 4pm: Toma
    - 5pm: Concentración máxima
    - 10pm-2am: Niveles terapéuticos buenos
    - 4am-4pm: **Niveles SUBTERAPÉUTICOS** (~12 horas desprotegido)

**Esquema correcto recomendado:**
- ✅ 500mg a las 4pm + 500mg a las 4am = 1000mg/día
- O mejor: 500mg cada 12h (ej: 8am y 8pm)
- Esto mantiene niveles constantes 24/7

### **Tolerancia:**
- ✅ Buena tolerancia vs fenitoína previa
- ✅ Metabolismo renal (ventaja vs hepático)
- ✅ Sin efectos adversos reportados

## 🧬 NEOM CARE IP - PROTOCOLO ANTI-EPILÉPTICO

**NEOM CARE IP** es el protocolo específico desarrollado por Emmanuel para controlar su epilepsia utilizando Cyberneom.

### **Componentes del protocolo:**

1. **Monitoreo EEG con Emotiv EPOC X (14 canales)**
    - Detección de patrones pre-ictales
    - Análisis de coherencia hemisférica
    - Identificación de desincronización temporal

2. **Sincronización hemisférica activa**
    - Binaural beats específicos para reducir hiperexcitabilidad
    - Modulación de ondas cerebrales (aumentar Alpha, reducir exceso de Beta)
    - Protocolo de frecuencias personalizadas

3. **Biofeedback respiratorio**
    - Sincronización respiración-ondas cerebrales
    - Técnicas de coherencia cardiaca integradas
    - Monitoreo en tiempo real

4. **Habit stacking riguroso**
    - Higiene de sueño estricta (8 horas consistentes)
    - Rutinas pre-sueño optimizadas
    - Eliminación de desencadenantes

5. **Intervención preventiva**
    - Detección temprana de patrones anormales
    - Sesiones correctivas antes de que escalten
    - Ajuste dinámico del protocolo

### **Resultados actuales:**

**Periodo sin crisis:** Julio 2025 - Enero 2026 = **6+ meses**
- Patrón histórico: Crisis cada ~2 meses
- 3 ciclos completados sin crisis
- Medicación: Levetiracetam 1000mg/día (mal horario pero dosis total)
- NEOM CARE IP implementado consistentemente

**Hipótesis de mecanismo:**
- Control = 70-80% NEOM CARE IP + 20-30% Levetiracetam
- Sincronización hemisférica reduce umbral epileptogénico
- Eliminación de desencadenantes (especialmente sueño) es clave
- Biofeedback permite autorregulación consciente

## 🔬 EVIDENCIA CIENTÍFICA DE NEUROFEEDBACK EN EPILEPSIA

**Estudios clave:**
1. **Sterman & Friar (1972)** - Trabajo pionero en neurofeedback para epilepsia
2. **Tan et al. (2009)** - Meta-análisis mostrando efectividad
3. **Egner & Sterman (2006)** - Reducción ~50% en frecuencia de crisis

**Mecanismo propuesto:**
- Entrenamiento de ritmo sensoriomotor (SMR)
- Incremento de ondas Alpha
- Reducción de hiperexcitabilidad cortical
- Mejora en sincronización hemisférica

**Ventajas vs farmacología:**
- Sin efectos secundarios
- Fortalece autorregulación natural
- No requiere medicación crónica
- Mejora calidad de vida general

## 🎛️ HARDWARE EEG - OPCIONES PARA CYBERNEOM

### **Dispositivos evaluados:**

**Emotiv EPOC X (14 canales) - ACTUAL**
- Uso: Sesiones diurnas intensivas Cámara Neom
- Pros: Cobertura completa, 14 canales, SDK robusto, batería 12h
- Contras para nocturno: Auriculares rígidos incómodos, sensores se mueven

**Emotiv Insight (5 canales) - RECOMENDADO PARA NOCTURNO**
- Canales: AF3, AF4, T7, T8, Pz
- ⭐ **T7/T8 capturan actividad temporal (clave para epilepsia temporal)**
- Pros: Balance comodidad/cobertura, batería 9h, más cómodo para dormir
- Contras: Menos resolución que EPOC X
- **RECOMENDACIÓN:** Mejor dispositivo para monitoreo nocturno

**MW20 (2 canales) - ENTRY LEVEL**
- Canales: Probablemente AF7, AF8 (frontales)
- Pros: Compacto, cómodo, económico
- Contras: Solo frontal, NO detecta actividad temporal
- Uso: Meditación básica, usuarios entry-level, NO para epilepsia temporal

**FLEX Salino/Gel (32 canales)**
- Pros: Cobertura completa investigación-grade
- Contras: Extremadamente incómodo, costoso ($3000+), overkill
- Uso: Solo para validación científica formal

**X-trodes (electrodos adhesivos desechables)**
- Pros: Máxima comodidad nocturna, permanecen en posición, configuración custom
- Contras: Desechables (costo recurrente), requiere EmotivPRO
- Potencial: Excelente si se logra integrar con Cyberneom

### **Setup óptimo recomendado:**

**DÍA:** Emotiv EPOC X (14 canales)
- Sesiones activas Cámara Neom
- Análisis profundo
- Neurofeedback intensivo

**NOCHE:** Emotiv Insight (5 canales)
- Monitoreo continuo T7/T8 (temporales)
- Detección patrones pre-ictales
- Cómodo para dormir

**OPCIONAL:** MW20 (2 canales)
- Para democratizar acceso
- Usuarios que no requieren análisis profundo
- Gateway hacia dispositivos más avanzados

class InsightDevice extends NeomEEGDevice {

  List<String> get channelNames => ['AF3', 'AF4', 'T7', 'T8', 'Pz'];

  bool get supportsTemporalMonitoring => true; // T7/T8
  
  @override
  bool get supportsSleepMonitoring => true;
  
  // Análisis específico epilepsia temporal
  Future<TemporalAsymmetryData> analyzeTemporalActivity() async {
    final t7Data = await getChannelData('T7');
    final t8Data = await getChannelData('T8');
    
    return TemporalAsymmetryData(
      leftPower: calculatePower(t7Data),
      rightPower: calculatePower(t8Data),
      asymmetryIndex: calculateAsymmetry(t7Data, t8Data),
      seizureRisk: assessSeizureRisk(t7Data, t8Data),
    );
  }
}

4. **Riesgo de suspensión prematura medicación:**
    - 6 meses sin crisis es excelente pero no definitivo
    - Reducción debe ser gradual y supervisada
    - Una crisis puede ser mortal (SUDEP, trauma)
